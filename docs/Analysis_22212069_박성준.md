## 1. Introduction
사용자의 개인 시간표를 분석하여 가용 시간에만 지능적으로 알림을 보내고, 업무의 우선순위와 연속 수행 성과를 시각화하며, 집중 모드(On/Off)를 통해 몰입을 돕는 웹 기반 지능형 플래너를 개발하는 것이다.

### 2-3. Use Case Model Notes

- `System`은 시스템 경계 내부의 구현 대상이므로 외부 Actor로 취급하지 않는다. 백그라운드 실행이 필요한 Use Case는 `Scheduler`가 Primary Actor로 시작한다.
- `Email Service`와 `Desktop Web Browser`는 알림을 실제로 전달하는 Secondary Actor로 분리한다.
- 사용자는 동시에 하나의 활성 Focus Session만 가질 수 있으며, 지연 알림은 해당 Focus Session과 연결된다.
- 알림 Use Case는 동일 조건의 중복 발송을 막기 위해 최근 알림 이력과 사용자 알림 허용 여부를 확인한다.

### GENERAL CHARACTERISTICS

| 항목 | 내용 |
|---|---|
| Summary | 사용자가 SURF the TAsk의 개인화된 플래너 기능을 사용하기 위해 회원 정보를 등록하는 기능이다. |

| Level | User Level |
| Author | 박성준 |
| Last Update | 2026-05-07 |
| Status | Analysis |
| Primary Actor | User |
| Preconditions | 시스템이 실행되어 있어야 하며, 사용자가 아직 로그인하지 않은 상태여야 한다. |

| 7 | 시스템은 회원가입 성공 메시지를 보여준다. |

| DeadlineTask | 마감 업무 | 마감 기한이 있는 업무를 나타내는 클래스 |
| CompletionRecord | 완료 기록 | 사용자가 특정 목표나 업무를 완료했는지 저장하는 클래스 |
| FocusSession | 집중 세션 | 사용자가 집중 모드를 시작하고 종료하는 과정을 나타내는 클래스 |
| Reminder | 알림 | 사용자에게 전송되는 알림 정보를 나타내는 클래스 |
| ReminderHistory | 알림 이력 | 알림 전송 성공, 실패, 제외 사유를 저장하여 중복 발송과 재시도를 관리하는 클래스 |
| NotificationPreference | 알림 설정 | 사용자의 이메일 알림, 내부 알림 허용 여부와 알림 간격 설정을 나타내는 클래스 |
| PriorityRule | 우선순위 규칙 | 중요도, 마감 임박도, 예상 수행 시간을 기반으로 업무 정렬 기준을 정의하는 클래스 |
| ProgressDashboard | 진행 현황 | 사용자의 완료율, streak, 우선순위 등을 보여주는 클래스 |
| ScheduleAnalyzer | 시간표 분석기 | 시간표를 기반으로 가용 시간을 계산하는 클래스 |
| ReminderEngine | 알림 처리기 | 가용 시간, 마감일, 집중 상태를 기준으로 알림 발생 여부를 판단하는 클래스 |

### 클래스 상세 리스트 (List Format)

- **User (사용자)**: SURF the TAsk를 사용하는 회원 정보를 나타내는 클래스
- **PersonalSchedule (개인 시간표)**: 사용자의 수업, 고정 일정, 개인 일정을 저장하는 클래스
- **AvailabilitySlot (가용 시간)**: 사용자의 시간표를 분석하여 생성된 빈 시간 구간을 나타내는 클래스
- **Task (업무/목표)**: 사용자가 수행해야 하는 목표 또는 업무의 공통 상위 클래스
- **DailyGoal (매일 목표)**: 매일 반복적으로 수행해야 하는 목표를 나타내는 클래스
- **DeadlineTask (마감 업무)**: 마감 기한이 있는 업무를 나타내는 클래스
- **CompletionRecord (완료 기록)**: 사용자가 특정 목표나 업무를 완료했는지 저장하는 클래스
- **FocusSession (집중 세션)**: 사용자가 집중 모드를 시작하고 종료하는 과정을 나타내는 클래스
- **Reminder (알림)**: 사용자에게 전송되는 알림 정보를 나타내는 클래스
- **ReminderHistory (알림 이력)**: 알림 전송 성공, 실패, 제외 사유를 저장하여 중복 발송과 재시도를 관리하는 클래스
- **NotificationPreference (알림 설정)**: 사용자의 이메일 알림, 내부 알림 허용 여부와 알림 간격 설정을 나타내는 클래스
- **PriorityRule (우선순위 규칙)**: 중요도, 마감 임박도, 예상 수행 시간을 기반으로 업무 정렬 기준을 정의하는 클래스
- **ProgressDashboard (진행 현황)**: 사용자의 완료율, streak, 우선순위 등을 보여주는 클래스
- **ScheduleAnalyzer (시간표 분석기)**: 시간표를 기반으로 가용 시간을 계산하는 클래스
- **ReminderEngine (알림 처리기)**: 가용 시간, 마감일, 집중 상태를 기준으로 알림 발생 여부를 판단하는 클래스

### 주요 관계 및 제약

| 관계/제약 | 내용 |
|---|---|
| User - PersonalSchedule | 한 명의 사용자는 여러 개의 개인 시간표 항목을 가질 수 있다. |
| User - Task | 한 명의 사용자는 여러 개의 Daily Goal과 Deadline Task를 등록할 수 있다. |
| Task - CompletionRecord | 하나의 Task는 날짜별 완료 기록을 여러 개 가질 수 있으며, Daily Goal의 streak 계산에 사용된다. |
| Task - FocusSession | 하나의 Task는 여러 Focus Session 기록을 가질 수 있지만, 한 사용자에게 동시에 활성화된 Focus Session은 하나만 허용한다. |
| PersonalSchedule - AvailabilitySlot | ScheduleAnalyzer는 개인 시간표를 분석하여 가용 시간 슬롯을 생성한다. |
| Reminder - ReminderHistory | ReminderEngine은 ReminderHistory를 확인하여 동일 조건의 중복 알림을 제한한다. |
| NotificationPreference - ReminderEngine | ReminderEngine은 사용자의 알림 허용 여부와 알림 간격 설정을 확인한 뒤 알림 전송 여부를 결정한다. |
| PriorityRule - Task | PriorityRule은 중요도, 마감 임박도, 예상 수행 시간을 기준으로 Task 표시 순서를 결정한다. |

## 6. Glossary

| Term | Meaning |
|---|---|
| To-do | 사용자가 수행해야 하는 할 일 또는 업무 |
| Daily Goal | 매일 반복적으로 수행해야 하는 목표 |
| Deadline Task | 정해진 마감 기한 이전에 완료해야 하는 업무 |
| Streak | 목표를 연속으로 수행한 일수 |
| Completion Rate | 전체 목표 대비 완료한 목표의 비율 |
| Priority | 업무의 중요도 또는 선행 처리 필요성을 나타내는 값 |
| Availability | 시간표 분석 결과 사용자가 수행 가능한 빈 시간 |
| On Mode | 사용자가 현재 특정 업무를 수행 중인 집중 상태 |
| Off Mode | 사용자가 집중 상태를 종료한 상태 |
| In-site Notification | 웹사이트 내부에서 표시되는 알림 |
| Focus Session | 사용자가 특정 목표 또는 업무에 대해 집중 모드를 시작한 뒤 종료하기까지의 기록 |
| Scheduler | 정해진 주기 또는 예약 시간에 알림 조건을 검사하는 백그라운드 실행 주체 |
| Notification Preference | 사용자가 이메일 알림과 사이트 내부 알림의 허용 여부 및 간격을 설정한 정보 |
| Reminder History | 알림 발송 성공, 실패, 제외 사유를 저장한 기록 |
| Priority Rule | 중요도, 마감 임박도, 예상 수행 시간을 조합하여 업무 순서를 정하는 기준 |
| Reminder Engine | 시간표, 미완료 목표, 마감일을 기반으로 알림 발송 여부를 결정하는 로직 |
| Timetable Analysis | 등록된 시간표를 바탕으로 가용 시간을 계산하는 과정 |
